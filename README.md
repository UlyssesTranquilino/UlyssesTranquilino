<details>
<summary><strong>FinCast — retrieval, model output, and financial calculations</strong></summary>

Built for managing my scholarship stipend and personal expenses.

- **Search:** Amazon Titan Text Embeddings V2 and Supabase pgvector retrieve transactions by meaning, with explicit date filters and transaction evidence.
- **Calculations:** backend code calculates monetary totals in integer centavos. Retrieval completeness and relevance remain separate from arithmetic correctness.
- **Receipt entry:** Bedrock extracts receipt fields for review before saving.
- **Monthly overview:** model-generated explanations use backend-calculated figures; calculated summaries remain available when AI is unavailable.
- **Forecasting:** an experimental XGBoost pipeline serves predictions through a Dockerized FastAPI backend. I distinguish forecasts from recorded financial facts.

**Stack:** Next.js, TypeScript, Python, FastAPI, Amazon Bedrock, Supabase/PostgreSQL, pgvector, Docker, Hugging Face Spaces, GitHub Actions.

</details>
